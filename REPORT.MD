# Отчёт по реализации HiFi-GAN
---

# 1. Полный пайплайн данных

## 1.1 Датасет: чтение аудио, сегментация и приведение формата

Файл: `src/datasets/ruslan_dataset.py`

Обучение HiFi-GAN выполняется не на целых аудиофайлах, а на коротких сегментах фиксированной длины. Это необходимо для:

* стабильного использования памяти GPU;
* одинаковых размеров батчей;
* ускорения итераций обучения;
* случайной аугментации за счёт выбора разных фрагментов сигнала.

Пайплайн обработки данных включает следующие шаги:

1. Рекурсивный поиск файлов `.wav` в директории датасета.
2. Загрузка аудио с помощью `torchaudio.load()`, что возвращает тензор формы `[channels, T]` и частоту дискретизации.
3. При необходимости выполняется ресемплирование до целевой частоты `target_sr`.
4. Приведение к моно-формату (усреднение каналов или выбор одного канала).
5. Нормализация амплитуды сигнала (обычно диапазон `[-1, 1]`).
6. Обрезка или дополнение нулями до фиксированной длины `segment_size`:

   * если аудио длиннее — выбирается случайное окно;
   * если короче — применяется zero-padding.

На выходе датасет возвращает:

* `wav` — тензор аудио;
* `path` — путь к файлу (для логирования и отладки).

## 1.2 DataLoader и формирование батча

Файл: `src/datasets/data_utils.py`

Поскольку все сегменты имеют одинаковую длину, функция `collate_fn` просто объединяет их в батч с помощью `torch.stack`.

Форма батча:

* `wav_batch`: `[B, T]`

# 2. Преобразование в mel-спектрограмму

Файл: `src/transforms/hifigan_mel.py`

Mel-преобразование является критически важной частью HiFi-GAN, поскольку модель обучается восстанавливать аудио именно из mel-представления. Поэтому вычисление mel на обучении и инференсе должно совпадать.

## 2.1 Вход и выход функции

Вход:

* waveform `[B, T]` или `[B, 1, T]`

Выход:

* log-mel спектрограмма `[B, n_mels, frames]`

где `n_mels` — число mel-каналов.

---

## 2.2 STFT

Преобразование выполняется с помощью короткого преобразования Фурье:

Параметры:

* `n_fft`
* `hop_length`
* `win_length`
* окно Hann

Алгоритм:

1. Padding сигнала по краям.
2. Вычисление комплексного спектра через `torch.stft`.
3. Получение амплитуды:

```
magnitude = sqrt(real² + imag²)
```

---

## 2.3 Mel filterbank

Переход от линейной частотной шкалы к mel-шкале:

```
mel = mel_basis @ magnitude
```

где `mel_basis` — матрица фильтров `[n_mels, freq_bins]`.

---

## 2.4 Логарифмическая компрессия

Используется динамическая компрессия диапазона:

```
log_mel = log(clamp(mel, eps))
```

Причины использования:

* уменьшение динамического диапазона;
* стабильность обучения;
* лучшее соответствие восприятию слуха человека.

# 3. Архитектура модели HiFi-GAN

Файл: `src/model/baseline_model.py`

Модель состоит из трёх основных компонентов:

1. Generator
2. Multi-Scale Discriminator (MSD)
3. Multi-Period Discriminator (MPD)

---

## 3.1 Generator

Генератор преобразует mel-спектрограмму в waveform.

Структура:

1. Вход: `[B, n_mels, frames]`
2. Начальная свёртка для увеличения числа каналов.
3. Несколько блоков апсемплинга (`ConvTranspose1d`).
4. После каждого апсемплинга — набор residual блоков (MRF).
5. Финальная свёртка и функция `tanh`.

Причина использования ConvTranspose1d:

Mel-спектрограмма имеет более редкую временную сетку, чем waveform, поэтому требуется увеличение временного разрешения.

---

## 3.2 Multi-Receptive Field Residual Blocks (MRF)

Каждый блок включает:

* свёртки с различными dilation;
* residual-соединение.

Назначение:

* захват зависимостей разной длины;
* моделирование формант и гармоник;
* стабильность градиента.

---

## 3.3 Multi-Scale Discriminator (MSD)

MSD состоит из нескольких дискриминаторов, анализирующих сигнал на разных масштабах времени:

* оригинальный сигнал;
* сигнал после downsampling;
* ещё более сжатый сигнал.

Это позволяет обнаруживать артефакты разной длительности.

Выход:

* оценки реальности;
* промежуточные feature maps.

---

## 3.4 Multi-Period Discriminator (MPD)

MPD анализирует периодическую структуру аудио.

Алгоритм:

1. Выбирается период `p` (например 2, 3, 5, 7, 11).
2. Сигнал преобразуется в двумерную форму `[T/p, p]`.
3. Применяются 2D-свёртки.

Назначение:

* контроль гармонической структуры;
* устранение металлических артефактов;
* улучшение качества речи и вокала.

---

# 4. Функции потерь

Файл: `src/loss/hifigan_loss.py`

Используется комбинация трёх типов потерь.

---

## 4.1 Adversarial Loss (LSGAN)

Дискриминатор:

```
L_D = (D(real) - 1)² + (D(fake))²
```

Генератор:

```
L_G_adv = (D(fake) - 1)²
```

LSGAN выбран из-за стабильности обучения.

---

## 4.2 Feature Matching Loss

Минимизируется расстояние между промежуточными активациями дискриминаторов:

```
L_FM = Σ |F_real - F_fake|
```

Назначение:

* стабилизация GAN-обучения;
* улучшение качества аудио;
* снижение артефактов.

---

## 4.3 Mel Reconstruction Loss

L1 расстояние между mel реального и сгенерированного сигнала:

```
L_mel = |Mel(real) - Mel(fake)|
```

Назначение:

* сохранение спектральной структуры;
* соответствие целевому тембру.

---

## 4.4 Итоговый лосс генератора

```
L_G = L_adv + λ_fm · L_fm + λ_mel · L_mel
```

Коэффициенты задаются в конфигурации.

# 5. Процесс обучения

Файл: `src/trainer/hifigan_trainer.py`

Обучение состоит из двух фаз.

---

## 5.1 Подготовка

1. Получение батча `real_wav`.
2. Вычисление `logmel_real`.
3. Генерация `fake_wav`.
4. Вычисление `logmel_fake`.

---

## 5.2 Обновление дискриминаторов

1. Прогон real и fake (с detach) через дискриминаторы.
2. Вычисление `loss_d`.
3. Backpropagation и шаг оптимизатора.

---

## 5.3 Обновление генератора

1. Прогон fake через дискриминаторы.
2. Вычисление adversarial, feature matching и mel лоссов.
3. Backpropagation и шаг оптимизатора генератора.

---

## 5.4 Mixed Precision (AMP)

При включении AMP используется `GradScaler`, что:

* ускоряет обучение;
* уменьшает потребление памяти GPU.

---

# 6. Инференс

Файл: `inference.py`

Процесс генерации аудио:

1. Загрузка wav.
2. Ресемплирование.
3. Вычисление mel.
4. Загрузка генератора из checkpoint.
5. Генерация waveform.
6. Сохранение результата.

Важно, что mel-преобразование полностью совпадает с обучением.

---

# 7. Управление экспериментами (Hydra)

Файл: `src/configs/baseline.yaml`, `train.py`

Hydra используется для конфигурации:

* датасетов;
* параметров mel;
* архитектуры модели;
* оптимизаторов;
* логирования.


---

# Заключение

В проекте реализована архитектура HiFi-GAN с генератором на основе апсемплинга и residual блоков, а также двумя типами дискриминаторов, что соответствует оригинальной статье. Используемая комбинация adversarial, feature matching и mel-loss обеспечивает стабильное обучение и высокое качество синтезируемого аудио.
